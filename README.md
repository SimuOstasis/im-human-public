## Описание принципов работы (простыми словами)

*Этот раздел объясняет принцип работы без формул и терминов. Технические детали — в разделах ниже.*

![[how-it-works.svg|Как работает im-human за 4 шага]]

im-human — это модель условного человека, состояние которого описывают 24 показателя
(биомаркера): глюкоза, холестерин, пульс, давление и другие.

Работа с программой сводится к четырём действиям:

1. **Выбрать профиль.** Молодой, средний возраст или пожилой. Профиль задаёт возраст, пол, вес и
   образ жизни (сон, стресс, питание, активность). От него зависят исходные значения биомаркеров и
   то, насколько быстро они меняются.
2. **Назначить вещества.** Витамины, добавки или препараты — например, омега-3, магний, метформин.
   Для каждого указывается доза и расписание приёма. Каждое вещество влияет на свой набор
   биомаркеров: одно снижает холестерин, другое — глюкозу.
3. **Запустить время.** Один шаг модели равен одному часу. Множители **×1 … ×10000** ускоряют
   расчёт: год модельного времени просчитывается меньше чем за секунду.
4. **Наблюдать за графиками.** Видно, как каждый показатель меняется во времени и куда движется.

**Что происходит внутри на каждом часе.** Программа повторяет один и тот же порядок расчётов:

- определяет текущую концентрацию каждого вещества в крови — после приёма она постепенно
  снижается, по мере выведения из организма;
- пересчитывает, как эти концентрации сдвигают биомаркеры, с учётом взаимного усиления и
  ослабления веществ;
- применяет **гомеостаз** — способность организма самому подтягивать показатели обратно к норме;
  с возрастом она слабеет;
- проверяет пороги: если показатель вышел за опасную границу, симуляция останавливается и выдаёт
  предупреждение.

**Результат воспроизводим.** Один и тот же профиль с одними и теми же веществами всегда даёт
одинаковый результат — при любом числе запусков и на любом компьютере. Это свойство называется
**детерминизмом**; оно нужно, чтобы сценарии можно было проверять, повторять и сравнивать между
собой.

**Ограничение.** Это исследовательская модель, а не медицинский инструмент. Числа отражают
поведение самой модели и не являются рекомендацией.

## Как это устроено (архитектура)

im-human состоит из четырёх слоёв: интерфейс, движок симуляции, данные и база знаний.

```mermaid
flowchart TB
    subgraph UI["🖥️ Интерфейс (PySide6 / Qt6)"]
        P["Панель профиля"]
        T["Управление временем ×1..×10000"]
        D["Дашборд 24 биомаркеров"]
        S["Менеджер веществ"]
        L["Журнал событий"]
    end
    subgraph ENG["⚙️ Движок симуляции (Python)"]
        PK["Фармакокинетика"]
        HO["Гомеостаз"]
        IR["Взаимодействия"]
        EV["Детектор событий"]
        MR["Биологический возраст"]
    end
    subgraph DATA["📦 Данные (JSON)"]
        SUB["substances.json"]
        INT["interactions.json"]
        REF["reference_ranges.json"]
        PRE["presets.json"]
    end
    subgraph KB["🧠 База знаний"]
        OB["Obsidian вики (истина)"]
        NEO["Neo4j граф + вектор"]
    end

    UI <-->|"сигналы / слоты (QThread)"| ENG
    DATA --> ENG
    OB <-->|"ingest_wiki.py"| NEO
```

| Слой | Технология | Назначение |
|------|-----------|-----------|
| UI | PySide6 (Qt6) | Десктопный интерфейс (панели, графики, управление) |
| Движок | Python 3.11+ | Симуляция — фармакокинетика, гомеостаз, события |
| Валидация | Pydantic v2 | Типобезопасные модели данных (HumanProfile, SimulationState) |
| Вики | Obsidian (Markdown) | База знаний о биомаркерах, веществах, движке |
| Граф/Векторная база | Neo4j | Граф связей + семантический поиск (384d эмбеддинги) |
| Тесты | pytest | 17 тест-файлов, 195 тестов |

### Хранение данных (DUAL-LAYER, ADR-002)

Все знания хранятся **одновременно в двух форматах**. При расхождении источников
**Obsidian является источником истины**.

```mermaid
flowchart LR
    A["✍️ Изменение страницы"] --> B["1. Markdown в Obsidian<br/>(истина)"]
    B --> C["2. ingest_wiki.py --changed-only"]
    C --> D["Neo4j: :Page, :Chunk<br/>векторный индекс 384d"]
    D -. "семантический поиск<br/>query_wiki.py" .-> B
```

Синхронизация вручную:
```powershell
cd W:\Obsidian\human\.neo4j
.\venv\Scripts\python.exe ingest_wiki.py --changed-only
```

## Как работает симуляция (цикл тика)

Сердце движка — **тик**: один шаг симуляции длиной 1 час. Каждый тик проходит строго
упорядоченный конвейер из 13 шагов (полное описание — в вики:
`06 - Engine/Simulation Engine.md`).

```mermaid
flowchart TD
    A["Тик = 1 час"] --> S2["Дозы по расписанию → концентрации"]
    S2 --> S3["PK-распад: C = C·e^(−ke)"]
    S3 --> S4["Эффекты веществ на биомаркеры"]
    S4 --> S5["Взаимодействия (синергия / антагонизм)"]
    S5 --> S6["Гомеостаз: дрейф + восстановление"]
    S6 --> S7["Зажим значений [0, max_safe]"]
    S7 --> S8["События: пороговые + вероятностные"]
    S8 --> S10["Биологический возраст + устойчивость"]
    S10 --> S12{"CRITICAL?"}
    S12 -- да --> PAUSE["⏸️ Автопауза + предупреждение"]
    S12 -- нет --> NEXT["Следующий тик"]
```

**Скорости.** Множитель = число тиков, которые движок считает за один «батч». Движок работает в
фоновом потоке (QThread) и считает тысячи тиков в секунду, а интерфейс перерисовывает графики
≈5 раз в секунду — поэтому окно не зависает даже на ×10000.

| Скорость | Тиков за батч | ≈ Время на 1 симулированный год |
|----------|---------------|--------------------------------|
| ×1 | 1 | ~2.4 часа |
| ×10 | 10 | ~14 минут |
| ×100 | 100 | ~1.5 минуты |
| ×1000 | 1000 | ~9 секунд |
| ×10000 | 10000 | < 1 секунды |

> Опорный факт производительности: бенчмарк рассчитывает 1 симулированный год (8760 тиков) менее
> чем за 5 секунд в оптимизированном режиме.

Подробные формулы каждого шага — в вики-разделе `06 - Engine/` (фармакокинетика, гомеостаз,
взаимодействия, детектор событий, биологический возраст, RNG).

## Установка

### Требования

- Python 3.11 или новее
- Neo4j 5.x / Neo4j Desktop (опционально — для работы с базой знаний)
- PySide6-совместимая графическая среда (для UI)

### Шаги установки

1. **Клонировать репозиторий:**

   ```powershell
   git clone <repo-url>
   cd human
   ```

2. **Создать виртуальное окружение:**

   ```powershell
   python -m venv venv
   ```

   > `venv` непереносим — его нельзя скопировать или переместить между машинами/папками. При
   > переносе проекта пересоздайте окружение заново: `python -m venv venv`, затем
   > `pip install -r requirements.txt`.

3. **Активировать окружение:**

   ```powershell
   # Windows (PowerShell)
   venv\Scripts\Activate.ps1

   # Windows (CMD)
   venv\Scripts\activate.bat
   ```

4. **Установить зависимости:**

   ```powershell
   pip install -r requirements.txt
   ```

5. **Настроить подключение к Neo4j** (опционально, для базы знаний):

   ```powershell
   copy .neo4j\.env.example .neo4j\.env
   # Открыть .neo4j\.env и указать реальные данные подключения:
   # NEO4J_URI=bolt://...
   # NEO4J_USER=...
   # NEO4J_PASSWORD=...
   # NEO4J_DATABASE=Human
   ```

## Быстрый старт

После установки:

```powershell
# 1. Активировать окружение (если не активировано)
venv\Scripts\Activate.ps1

# 2. Запустить приложение
python src/main.py
```

Приложение откроет главное окно с панелью профиля, управлением временем, дашбордом биомаркеров и
менеджером веществ. Рабочий процесс: **выбрать пресет профиля → добавить вещество (доза, интервал) →
выбрать скорость → «Запустить» → наблюдать динамику 24 биомаркеров.** Пошаговая инструкция —
в вики: `06 - Engine/User Guide.md` и `05 - Simulation/UI Guide.md`.

## Биомаркеры MVP (24 наблюдаемых)

ЛПНП, ЛПВП, Триглицериды, ApoB, Глюкоза, Инсулин, HOMA-IR, HbA1c,
hs-CRP, IL-6, АЛТ, АСТ, ГГТ, Альбумин, Креатинин, eGFR, UACR,
Натрий, Калий, 25(OH)D, Гемоглобин, АД, Пульс, HRV.

Внутренние индексы: `oxidativeStressIndex`, `systemicInflammationIndex`,
`insulinSensitivityIndex`, `autophagyActivity`, `senescentCellBurden`, `biologicalAge`.

### Вещества (7) и взаимодействия (6)

Источник — `src/data/substances.json` и `src/data/interactions.json`.

| Вещество | Категория | EvidenceLevel |
|----------|-----------|---------------|
| Омега-3 | supplement | high |
| Витамин D3 | supplement | high |
| Магний | supplement | high |
| Берберин | supplement | moderate |
| Метформин ⚠️ | drug | high |

Полная матрица — вики `04 - Interactions/Interactions Index.md`.
