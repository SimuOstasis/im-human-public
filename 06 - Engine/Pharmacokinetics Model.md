# Фармакокинетическая модель

Одночастотная экспоненциальная модель (1-compartment first-order elimination), используемая в движке симуляции im-human.

## Формулы

### Константа элиминации (ke)
```
ke = ln(2) / T½
```
где T½ — период полувыведения (часы).

### Концентрация при дозировании (Cmax increment)
```
ΔC = D × F / (Vd × W)
```
где D — доза (мг), F — биодоступность (0–1), Vd — объём распределения (л/кг), W — вес (кг).

### Экспоненциальный распад (за 1 тик = 1 час)
```
C(t+1) = C(t) × e^(−ke)
```

### Масштабирование эффекта на биомаркер (D-04 из Phase 4)
```
Δbiomarker = effectProfile[code] × C(t) / Cmax
```

## Особые случаи

### Vitamin D3 (единица: IU)
Доза конвертируется перед расчётом:
```
dose_mg = dose_IU × 0.000025
```
Концентрация хранится в нативных единицах (мг/л); масштабирование C/Cmax безразмерно.

### Кумуляция при повторных дозах
При каждой дозе: C_new = C_old + ΔC (суперпозиция).
Кумуляция до плато при ke × T_дозирование < 1.

### Rapamycin — циклическое дозирование
Расписание CycleConfig: on_days=1, off_days=6 (1 раз в неделю).
AdaptiveStepper.should_dose() проверяет цикл на каждом тике.
