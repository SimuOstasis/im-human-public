# Руководство пользователя

Пошаговое руководство по работе с приложением im-human — симулятором биологической модели человека.

> **Дисклеймер:** Это исследовательская симуляция, а не медицинский диагностический инструмент.
> Результаты не являются медицинской рекомендацией. Все числа отражают внутреннюю механику модели.
> Рапамицин и метформин — рецептурные препараты.

---

## Запуск приложения

1. Убедитесь, что виртуальное окружение активировано:

   ```powershell
   # Windows PowerShell
   venv\Scripts\Activate.ps1
   ```

2. Запустите приложение:

   ```powershell
   python src/main.py
   ```

3. Откроется главное окно с четырьмя панелями:
   - **Профиль** (слева) — параметры человека, управление симуляцией
   - **Дашборд биомаркеров** (центр) — 24 биомаркера с референсными диапазонами
   - **Вещества / Биомаркеры** (справа, вкладки) — менеджер веществ и полный список биомаркеров
   - **Журнал событий** (снизу) — критические события симуляции

## Создание профиля

Профиль определяет физические параметры человека, от которых зависят фармакокинетика и базовые значения биомаркеров.

### Выбор пресета

В панели **Профиль** выберите в списке пресетов один из трёх вариантов (`src/data/presets.json`):

| Пресет (`profile_id`) | Отображаемое имя | Описание |
|------------------------|------------------|---------|
| `young_healthy_30m` | Молодой здоровый 30M | Мужчина 30 лет, 75 кг, умеренная активность, оптимальные показатели |
| `middle_age_50f` | Средний возраст 50F | Женщина 50 лет, 70 кг, низкая активность, сниженная аутофагия, умеренные риски |
| `elderly_70m` | Пожилой 70M | Мужчина 70 лет, 80 кг, сидячий образ жизни, повышенные сердечно-сосудистые и метаболические риски |

### Параметры профиля

После выбора пресета можно скорректировать:

- **Возраст** — влияет на скорость гомеостаза и биологический возраст
- **Вес (кг)** — используется в расчёте Cmax (объём распределения вещества)
- **Пол** — определяет половозависимые референсные диапазоны биомаркеров
- **Уровень физической активности** — множитель гомеостатического восстановления

### Применение профиля

Нажмите кнопку **«Запустить»** для старта симуляции с текущим профилем. Биомаркеры инициализируются
на базовых значениях, соответствующих профилю (середина оптимального диапазона по полу и возрасту).

## Добавление вещества

Вещества изменяют биомаркеры через фармакокинетическую модель — концентрация в крови
нарастает при каждой дозе и экспоненциально убывает с периодом полувыведения.

### Шаги добавления

1. Перейдите на вкладку **«Вещества»** в правой панели.
2. Нажмите кнопку **«Добавить»**.
3. В диалоге выберите вещество из списка (Omega-3, Vitamin D3, Magnesium, Berberine, Metformin, Rapamycin, NMN).
4. Укажите параметры дозирования:
   - **Доза** — количество (мг или IU для Vitamin D3)
   - **Интервал приёма** — каждые N часов (например, 24 = 1 раз в сутки)
   - **Для Rapamycin:** циклический режим: 1 день приёма / 6 дней паузы

5. Нажмите **«Применить»**. Вещество появится в таблице активных веществ.

### Скорость симуляции

Управление временем осуществляется кнопками **×1 / ×10 / ×100 / ×1000 / ×10000**:

| Множитель | Реальное время на симул. год |
|-----------|------------------------------|
| ×1 | ~8760 секунд (~2.4 часа) |
| ×10 | ~876 секунд (~14 минут) |
| ×100 | ~88 секунд |
| ×1000 | ~9 секунд |
| ×10000 | < 1 секунды |

Цифры ориентировочны и зависят от процессора: движок считает тысячи тиков в секунду, а интерфейс
перерисовывает графики примерно 5 раз в секунду (см. [[Simulation Engine]] и
[[Adaptive Stepper]]). Опорный факт: бенчмарк считает 1 симулированный год (8760 тиков)
менее чем за 5 секунд в оптимизированном режиме.

Рекомендуется начать с ×10 и переключиться на ×1000 для долгосрочных симуляций.

### Удаление вещества

Выберите вещество в таблице и нажмите **«Удалить»**. Вещество немедленно прекращает
воздействие; концентрация в крови продолжает убывать по закону элиминации.

## Сохранение и загрузка

Сохранение и загрузка состояния симуляции доступны прямо из главного окна —
через меню **«Файл»**:

| Пункт меню | Горячая клавиша | Действие |
|------------|-----------------|----------|
| **Файл → Сохранить** | `Ctrl+S` | Открывает диалог выбора файла и сохраняет текущее состояние симуляции (профиль, активные расписания доз, значения биомаркеров, состояние генератора случайных чисел) в JSON |
| **Файл → Загрузить** | `Ctrl+O` | Открывает диалог выбора файла и восстанавливает ранее сохранённую симуляцию — профиль, вещества и биомаркеры возвращаются к сохранённому состоянию |

Пункты **«Сохранить»** и **«Загрузить»** недоступны (затемнены), пока симуляция находится
в состоянии **RUNNING** — остановите (пауза) или дождитесь паузы перед сохранением/загрузкой.

### Формат файла

Симуляция сохраняется в JSON с полным снепшотом:

```json
{
  "version": "1.0",
  "exported_at": "2026-06-24T12:00:00",
  "profile": { "...все поля HumanProfile..." },
  "schedules": [ "...список активных расписаний доз..." ],
  "state": { "...biomarker_values, substance_concentrations, rng_state, tick_count..." }
}
```

### Детерминированное возобновление

Состояние генератора случайных чисел (`rng_state`) сохраняется в файле.
После загрузки симуляция продолжается побитово идентично исходному прогону —
это гарантирует воспроизводимость исследовательских сценариев. После загрузки
приостановленной (PAUSED) симуляции нажмите **«Запустить»**, чтобы продолжить.

### Программный доступ

Тот же формат доступен и напрямую из кода через модуль `src/engine/exporter.py`
(API: `save_simulation` / `load_simulation`) — например, для скриптов пакетной
генерации сценариев без запуска UI.

```python
from pathlib import Path
from src.engine.exporter import save_simulation, load_simulation

# engine — запущенный SimulationEngine, profile — HumanProfile, schedules — list[IntakeSchedule]
save_simulation(engine.state, profile, schedules, Path("my_simulation.json"))

state, profile, schedules = load_simulation(Path("my_simulation.json"))
```

## Экспорт графиков

Есть два способа сохранить графики биомаркеров из дашборда в файл — для одного графика
и для всех сразу.

### Экспорт одного графика

Кликните правой кнопкой мыши на любом из 24 графиков дашборда биомаркеров — откроется
штатное контекстное меню PyQtGraph. Выберите **«Export...»** и укажите формат (PNG или SVG)
и путь сохранения.

### Экспорт всех графиков разом

Пункт меню **«Файл → Экспорт всех графиков»** сохраняет все 24 графика дашборда за один
проход:

1. Выберите пункт **«Файл → Экспорт всех графиков»**.
2. Один раз укажите формат — **PNG** или **SVG** (выбор применяется ко всем 24 файлам).
3. Выберите папку назначения — диалог выбора папки открывается при каждом запуске
   (фиксированной папки по умолчанию нет).
4. Все графики сохраняются в выбранную папку с именами вида `{код_биомаркера}_{timestamp}.{png|svg}`
   (код биомаркера — из `src/data/biomarkers.json`, например `ldl_20260717_1530.png`).

После завершения появится сообщение с числом успешно экспортированных графиков.

## Интерпретация biologicalAge / resilience

Значения **биологического возраста** (`biologicalAge`) и **устойчивости** (`resilience`)
в дашборде и журнале событий помечены символом **≈** — это ориентировочный индекс,
рассчитанный по внутренней механике модели (упрощённая линейная форма PhenoAge,
см. [[Biological Age Formula]]), а **не** клинически валидированный медицинский показатель.

Числа полезны для сравнения сценариев внутри одной симуляции (например, «с веществом X
ориентировочный индекс ниже, чем без него»), но не отражают реальный биологический возраст
конкретного человека. Подробное объяснение упрощений модели — в [[Known Limitations]].
