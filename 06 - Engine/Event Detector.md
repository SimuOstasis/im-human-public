# Детектор событий

Модуль преобразует значения биомаркеров в объекты `SimulationEvent` двух типов: пороговые нарушения (`THRESHOLD_BREACH`) и вероятностные события (`PROBABILISTIC`). `CRITICAL` события автоматически паузируют FSM симуляции. Реализован в `src/engine/event_detector.py`.

## Формула/Алгоритм

### Тип 1: THRESHOLD_BREACH (пороговые нарушения)

Сравнивает текущее значение биомаркера с зоной `high_risk` из `reference_ranges.json`.

#### Обычные биомаркеры (LDL, Глюкоза, hs-CRP и др.)

Риск при значении **выше** порога (`high_risk[0]`):

```
val >= high_risk[0]          → WARNING
val >= high_risk[0] × 1.3   → CRITICAL
```

#### Инвертированные биомаркеры (HDL, eGFR, Albumin, HRV, Гемоглобин)

Риск при значении **ниже** порога (`high_risk[1]`):

```
val <= high_risk[1]          → WARNING
val <= high_risk[1] × 0.8   → CRITICAL
```

Полный список инвертированных биомаркеров (константа `INVERTED_BIOMARKERS`):
`hdlC`, `egfr`, `albumin`, `hrvRmssd`, `hemoglobin`

**Защита от NaN/Inf:** `math.isfinite(val)` — значения без конечного представления пропускаются (T-05-09).

### Тип 2: PROBABILISTIC (вероятностные события)

Конвертация 10-летнего клинического риска в per-tick вероятность:

```
p_tick = 1 - (1 - p_10yr)^(1 / 87600)
```

где `87600` = 10 лет × 365 дней × 24 часа = количество тиков за 10 лет.

#### 2.1 Кардиоваскулярный риск (CVD)

```
ldl_factor = max(1.0, ldl / 2.5)
bp_factor  = max(1.0, 1.0 + (sbp - 120.0) / 40.0)
age_factor = max(1.0, (age - 40) / 10.0)
sex_mult   = 1.3  если male, иначе 1.0

p_10yr  = min(0.8, CVD_BASE_10YR × ldl_factor × bp_factor × age_factor × sex_mult)
p_tick  = 1 - (1 - p_10yr)^(1 / 87600)
```

#### 2.2 Риск диабета

Активируется только при `HbA1c > 5.7` **и** `глюкоза > 5.5`:

```
p_10yr_dm  = min(0.5, 0.1 × (hba1c - 5.7) / 0.8)
p_tick_dm  = 1 - (1 - p_10yr_dm)^(1 / 87600)
```

#### 2.3 Риск снижения функции почек (CKD)

Активируется только при `креатинин > 115` **и** `eGFR < 70`:

```
p_10yr_ckd = min(0.3, 0.05 × (1.0 - egfr / 90.0))
p_tick_ckd = 1 - (1 - p_10yr_ckd)^(1 / 87600)
```

#### 2.4 Гипертонический криз

Активируется при `АД сист. > 160 мм рт.ст.` (CRITICAL):

```
если sbp > 160 и rng.random() < 0.001 → CRITICAL SimulationEvent
```

## Параметры

| Константа | Значение | Источник | Описание |
|-----------|----------|----------|----------|
| `CVD_BASE_10YR` | 0.05 | `event_detector.py:35` | Базовый 10-летний кардиоваскулярный риск (5%) |
| `INVERTED_BIOMARKERS` | `{hdlC, egfr, albumin, hrvRmssd, hemoglobin}` | `event_detector.py:26-32` | Биомаркеры с риском при низком значении |
| Горизонт конвертации | 87600 тиков | `event_detector.py:162` | 10 лет × 365 × 24 часа |

## Пример (вход → выход)

**Пример THRESHOLD_BREACH — LDL:**

| Вход | Значение |
|------|----------|
| LDL (`ldlC`) | 4.5 ммоль/л |
| `high_risk[0]` из reference_ranges | 3.4 ммоль/л |

```
val >= 3.4    → WARNING (4.5 >= 3.4: True)
val >= 3.4 × 1.3 = 4.42 → CRITICAL (4.5 >= 4.42: True)
Результат: SimulationEvent(severity="CRITICAL", biomarker="ldlC", value=4.5)
```

**Пример PROBABILISTIC — CVD (мужчина, 55 лет, LDL=3.8, АД=140):**

```
ldl_factor = max(1.0, 3.8 / 2.5)     = 1.52
bp_factor  = max(1.0, 1 + (140-120)/40) = 1.5
age_factor = max(1.0, (55-40)/10)    = 1.5
sex_mult   = 1.3 (male)

p_10yr  = min(0.8, 0.05 × 1.52 × 1.5 × 1.5 × 1.3) = min(0.8, 0.222) = 0.222
p_tick  = 1 - (1 - 0.222)^(1/87600) ≈ 2.84 × 10⁻⁶ за тик

Вероятность ~0.000284% за тик → ~2.5% в год.
```

## Ограничения

- **Упрощённые риск-факторы CVD:** модель не учитывает курение, семейный анамнез, статины — в отличие от клинических калькуляторов Framingham/SCORE.
- **Линейная интерполяция факторов:** `ldl_factor`, `bp_factor` — линейные коэффициенты, не логистические кривые.
- **Нет взаимодействия рисков:** CVD и диабет проверяются независимо; реальная коморбидность мультипликативна.
- **Фиксированный `CVD_BASE_10YR = 0.05`:** не учитывает популяционные различия по регионам и этническим группам.
- **Гипертонический криз (p=0.001/тик):** простая пороговая константа, не масштабируется с уровнем АД выше 160.
